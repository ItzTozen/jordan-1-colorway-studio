# Air Jordan 1 — Colorway Studio II (نسخهٔ مینیمال)

نسخهٔ دوم لندینگ Air Jordan 1 با زبان بصری مینیمال‌تر: فونت **Anton** (حس فونت نایک)، سوییچر **کارت‌های عکس‌دار شناور** در هیرو و سکشن **«COLORWAY INDEX»** به‌صورت استریپ افقی scroll-snap با تگ‌های WEARING / WEAR IT.

همان موتور پروژهٔ اصلی: ۶ رنگ‌وی، پس‌زمینهٔ پوستری با کراس‌فید، پارالاکس سه‌بعدی، سبد خرید drawer.

```bash
npm install
npm run dev        # → http://localhost:5174
npm run build && npm start   # production → http://localhost:3001
```

دسترسی از موبایل/لپ‌تاپ روی همان وای‌فای: http://192.168.1.5:5174

**مستندات کامل بازسازی، باگ‌ها و نکات امنیتی: [Rule.md](./Rule.md)** — حتماً بخوان.
